# Study — общий учебный репозиторий
Добро пожаловать в учебный репозиторий!

Здесь студенты учатся работать в команде через Git и GitHub: клонировать, ветвиться, коммитить, отправлять Pull Request и проходить ревью.

---

## Цель репозитория

Практическое освоение **командной работы с Git**:

- Клонирование общего репозитория
- Создание личных веток
- Осмысленные коммиты
- Отправка изменений через `git push`
- Оформление Pull Request
- Ревью кода товарищей
- Разрешение конфликтов
